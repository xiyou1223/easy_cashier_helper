# 便利收银助手 🛒

一款面向小卖部、便利店收银计价场景的微信小程序——扫码即用，纯本地存储，完全免费。

## 功能

- **扫码计价**：底部大按钮扫码，商品自动加入购物车并累加金额
- **购物车管理**：修改数量、删除单品、一键清空、抹零结算
- **商品管理**：增删改查、条码搜索、长按编辑、导入/导出数据备份
- **纯本地运行**：所有数据存储在手机本地，无需注册、无需联网

## 截图预览

| 导航首页 | 收银计价 | 商品管理 |
|---------|---------|---------|
| 两个大入口按钮，跳转收银或商品管理 | 底部扫码按钮 + 购物车列表 + 抹零/清空 | 新增/搜索/编辑/删除商品 |

## 快速开始

1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 克隆本项目，在开发者工具中打开 `miniprogram/` 目录
3. 填入自己的 AppID（或使用测试号）
4. 点击编译即可运行

## 项目结构

```
miniprogram/
├── app.js               # 全局生命周期，初始化演示数据
├── app.json             # 页面路由（3 页，无 tabBar）
├── app.wxss             # 全局样式
├── project.config.json  # 项目配置
├── utils/
│   └── storage.js       # 本地存储封装（唯一数据层）
├── pages/
│   ├── index/           # 入口导航页
│   ├── cashier/         # 收银计价页（扫码 + 购物车 + 结算）
│   └── goods/           # 商品管理页（CRUD + 搜索 + 导入导出）
└── images/              # 资源目录
```

## 技术栈

- **框架**：微信小程序原生（无第三方框架）
- **存储**：`wx.setStorageSync` 本地缓存（无云服务、无后端）
- **基础库**：3.5.0+
- **兼容**：iOS 12.0+ / Android 7.0+ / 微信 8.0+
- **无 npm 依赖**，开箱即用

## 设计规范

- 主色调：`#ff6b35`（橙色）

- 风格：卡片式、圆角、白底
